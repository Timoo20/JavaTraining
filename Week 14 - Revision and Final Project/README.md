# Week 14 - Revision and Final Examination

Full task instructions: see `WEEK 14 - Practical - Final Revision Lab.docx` in the PRACTICALS folder.

**Files in this folder**

A small Library Management example that deliberately pulls together most of what we covered this semester: abstraction, inheritance, polymorphism, encapsulation, collections and custom exceptions.

- `LibraryItem.java` - abstract class with a private `borrowed` flag and an abstract `getItemType()` method.
- `Book.java` / `Magazine.java` - two subclasses of LibraryItem.
- `ItemNotAvailableException.java` - a custom exception thrown when an item is already borrowed.
- `LibraryDemo.java` - stores items in an ArrayList, displays them, and demonstrates the exception being thrown.

Study how these files fit together, then use the same kind of thinking to design your own mini project for revision, as described in the practical document.
