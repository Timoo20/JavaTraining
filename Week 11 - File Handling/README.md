# Week 11 - File Handling in Java

Full task instructions: see `WEEK 11 - Practical - File Handling.docx` in the PRACTICALS folder.

**Files in this folder**

- `FileWriterDemo.java` - writes three student records to `students.txt`.
- `FileReaderDemo.java` - reads `students.txt` back and prints it.
- `FileAppendDemo.java` - adds one more record without deleting what is already there.

Run these three in order (write, read, append, read again) to see the full picture.
