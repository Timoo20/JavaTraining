# Week 7 - Polymorphism and Interfaces

Full task instructions: see `WEEK 07 - Practical - Polymorphism and Interfaces.docx` in the PRACTICALS folder.

**Files in this folder**

- `Calculator.java` / `CalculatorDemo.java` - method overloading: three `add` methods, same name, different parameters.
- `Payable.java`, `SalariedEmployee.java`, `HourlyEmployee.java`, `PayableDemo.java` - an interface implemented two different ways.
- `Animal.java`, `Dog.java`, `Cat.java`, `PolymorphismDemo.java` - runtime polymorphism: the same reference type, two different behaviours at runtime.
