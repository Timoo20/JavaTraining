# Week 9 - Exception Handling and Debugging

Full task instructions: see `WEEK 09 - Practical - Exception Handling and Debugging.docx` in the PRACTICALS folder.

**Files in this folder**

- `ExceptionBasics.java` - catches ArithmeticException and InputMismatchException, with a finally block.
- `InsufficientFundsException.java`, `BankAccount.java`, `BankAccountExceptionDemo.java` - a custom exception thrown from withdraw().
- `BuggyAverage.java` - deliberately broken code for the debugging task. Set a breakpoint and step through it before fixing anything.
- `FixedAverage.java` - the corrected version, for you to compare against once you have tried fixing it yourself.
