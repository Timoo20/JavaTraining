# Week 5 - Encapsulation and Abstraction

Full task instructions: see `WEEK 05 - Practical - Encapsulation and Abstraction.docx` in the PRACTICALS folder.

**Files in this folder**

- `BankAccount.java` / `BankAccountDemo.java` - a private balance field, controlled only through deposit(), withdraw() and getBalance().
- `Shape.java` - an abstract class with one abstract method, calculateArea().
- `Circle.java` / `Rectangle.java` - two subclasses, each implementing calculateArea() in its own way.
- `ShapeDemo.java` - creates a Circle and a Rectangle and prints each area.
