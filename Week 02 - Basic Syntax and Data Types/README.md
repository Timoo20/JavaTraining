# Week 2 - Basic Java Syntax and Data Types

Full task instructions: see `WEEK 02 - Practical - Variables, Data Types and Scanner Input.docx` in the PRACTICALS folder.

**Files in this folder**

- `SimpleInterestCalculator.java` - reads Principal, Rate and Time from the keyboard and works out simple interest.
- `BMICalculator.java` - reads weight and height and calculates BMI.
- `TemperatureConverter.java` - converts a Celsius value to Fahrenheit.

Run each one, enter your own values when prompted, and check that the output makes sense before you move on to your own practical submission.
